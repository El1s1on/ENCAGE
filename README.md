# ENCAGE

Мультиплеерный мелее-файтинг от первого лица на **Unity 6 (6000.3)** и **FishNet 4.6**.
Проект сделан как техническая демонстрация серверно-авторитетной боёвки: движение с client-side prediction, а атаки, блоки и попадания проверяются сервером.

> Статус: прототип в разработке (последний коммит: май 2026).

## Что реализовано

### Движение: prediction и reconciliation
- `[Replicate]` / `CreateReconcile` на тиках FishNet, ввод игрока собирается в структуру и применяется одинаково на клиенте и сервере.
- Ходьба, спринт, прыжок, гравитация, койот-тайм, прилипание к склонам.
- Выносливость (тратится на спринт, прыжок и атаки, регенерация с задержкой).
- Стан и отброс, привязанные к тикам, а не ко времени, поэтому они воспроизводятся при reconcile.

### Боёвка: серверная авторитетность
- Клиент отправляет только намерение (`[ServerRpc]`: начать атаку, атаковать, блок, снять блок). Решение о том, можно ли это сделать, принимает сервер.
- Сервер проверяет состояние игрока: рэгдолл, стан, уже идущая атака, выносливость, допустимое сочетание атака/блок.
- Клиенту возвращается только результат (`[TargetRpc]`), состояние боя всегда определяет сервер.
- **Валидация попаданий:** клиент присылает репорт попадания, сервер проверяет его по окну тиков атаки (`hitWindowStart` / `hitWindowEnd`) и отбрасывает невалидные.
- Данные оружия и атак вынесены в ScriptableObject (`WeaponData`, `AttackData`, `DefenseData`): длительность, стоимость выносливости, урон и его разброс, размеры хитбокса, окно попадания.

### Остальное
- Хитбоксы (`HitboxGroup`, `HitboxPhysics`), рэгдолл, IK-анимации, звуки шагов, UI игрока.
- Редакторский инструмент `MirrorAnimationClip` для зеркалирования анимаций.

## Где мой код

Весь собственный код лежит в `Assets/!ENCAGE/Scripts`:

| Папка | Содержимое |
|---|---|
| `Player/` | движение, бой, здоровье, рэгдолл, камера, ввод, UI |
| `Combat/` | хитбоксы и физика попаданий |
| `SO/` | данные оружия и атак |
| `Editor/` | инструменты для редактора |

Остальные папки в `Assets/` содержат сторонние ассеты и плагины (FishNet, Synty, Opsive, KriptoFX, ParrelSync, ALINE и др.).

## Известные ограничения
- Компенсация лагов для попаданий пока опирается на окно тиков, полноценный rollback коллайдеров не используется.
- Проект на стадии прототипа: отлаживаются стан и взаимодействие атак.

## Запуск
1. Открыть проект в Unity 6000.3.x.
2. Открыть сцену из `Assets/!ENCAGE/Scenes` (например `TestScene`).
3. Для проверки мультиплеера использовать ParrelSync (клон проекта) или запустить хост и клиент в двух экземплярах.
